# Hydroponics Monitoring & Management Web App

A web application for monitoring hydroponic systems, managing user authentication, and viewing system logs and dashboard metrics.

## Features
- **User Authentication:** Login and registration pages (`login.html`, `register.html`).
- **Dashboard:** Real-time/visual overview of hydroponic system parameters (`dashboard.html`).
- **System Logs:** Historical tracking and activity logs (`logs.html`).
